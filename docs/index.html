HumanBuilder

🚀 An autonomous Litematica builder that places your schematic like a real player — natural aiming, human timing, and a wandering walk — so you can see how long a build would actually take by hand.

✦ What it does

🛰️

Builds it for you

Reads the schematic you place in Litematica and lays every block automatically, one at a time — no clicking for hours.

🧠

Thinks like Baritone

Always goes for the nearest block it can place, builds the supports first, and plans the smartest route to get there.

🪐

Moves like a human

Walks with a natural little wander, aims with realistic timing and tiny imperfections — not a robot gliding on rails.

☄️

Lag-aware

Watches the server's TPS and slows down — or pauses and waits — when things get choppy, then picks back up on its own.

🧱

Places blocks right

Slabs, stairs, pillars and directional blocks all end up facing the correct way, checked against the game's own rules.

⏱️

Time estimate

A live on-screen readout of blocks placed, blocks per minute and an ETA — the whole point: know how long the real build takes.

✦ What you need

Install these Fabric mods for Minecraft 1.21.11 alongside HumanBuilder:

▸ Fabric API
▸ Litematica (sakura-ryoko 0.26.11+)
▸ malilib
▸ Cloth Config (optional — settings menu)
▸ Mod Menu (optional — settings menu)

✦ Get started

  1. Grab the HumanBuilder jar with the button above.
  2. Drop it into your .minecraft/mods folder, along with Fabric API, Litematica and malilib.
  3. Launch Minecraft 1.21.11 using the Fabric profile.
  4. Load a schematic in Litematica and place it where you want to build.
  5. Stand nearby with the needed blocks in your inventory, then press B to start or stop.
  6. Watch the on-screen panel: blocks placed · per minute · ETA — that's your estimate. 🌌
Made for personal use. HumanBuilder is for singleplayer and your own server, to estimate how long a manual build takes. It's client-side and never fakes network packets — it only presses the same keys and moves the same mouse you would. The human-like imperfection is there to make the time estimate realistic (and to make recordings look natural), not to beat any anti-cheat.
